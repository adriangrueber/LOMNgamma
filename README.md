# LOMNgamma
R-Code for the estimation of the noise tail parameter in a LOMN-model under gamma distributed microstructure noise.

We provide the R scripts used to generate the figures within the manuscript "Asset-specific limit order microstructure noise: Parameter estimation and empirical evidence" (https://doi.org/10.48550/arXiv.2608.05838). The R code for simulating the AVAR function, displayed in Fig. 1, can be found under "Avar-function.r". The R code used to simulate the histograms in Fig. 2, can be found under "hists-alpha-hat.r". Additionally, one can find the implementations of the corresponding moment estimators for beta and asymptotic confidence intervals with power p in the file.
